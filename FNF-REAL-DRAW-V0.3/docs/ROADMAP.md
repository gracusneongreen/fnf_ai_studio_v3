# V0.3 Roadmap

## Stage 1 — Character Master
Generate one stable master image and store it as the identity anchor.

## Stage 2 — Pose Engine
Generate the five rhythm-game poses from the same anchor.

## Stage 3 — Consistency
Compare each frame against the master and reject frames with changed clothes,
hair, palette, proportions or missing anatomy.

## Stage 4 — Corruption
Generate controlled phase changes while preserving the base identity.

## Stage 5 — Animation
Create frame sequences and timing metadata.

## Stage 6 — Export
Build PNG sprite sheets and Sparrow XML compatible with the target engine.

## Stage 7 — Psych Engine
Generate a ready-to-import character asset package.

## Future
- interactive drawing canvas
- body-part extraction
- rig-assisted animation
- onion skin
- automatic XML offsets
- batch character generation
- local GPU backend
- API backends
