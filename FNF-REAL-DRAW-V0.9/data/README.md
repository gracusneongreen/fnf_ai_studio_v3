# REAL POSE AI data

Recommended coverage is a mixture of:
- idle
- walk
- run
- jump
- fall
- turn
- crouch
- lean
- dance
- singing
- reactions
- transitions

Prefer complete sequences with many consecutive frames. Record FPS, confidence, camera/source metadata and authorization information.

More files alone do not guarantee better motion. Diversity + accurate keypoints + temporal labels + quality control are the important parts.
